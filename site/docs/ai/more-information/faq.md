# FAQ

## Which AI providers does ONLYOFFICE support?

The AI plugin supports a wide range of providers, including OpenAI, DeepSeek, Google Gemini, Anthropic Claude, Mistral, Ollama, and any provider compatible with the OpenAI API format. See [custom providers](../ai/custom-providers.md) for details.

## How do I configure the AI plugin?

After installing the plugin, go to **AI → Settings → Edit AI models**, add your provider, enter your API key, and select what each model is used for. Full setup instructions are in the [AI plugin guide](../ai/ai-plugin.md#configuring).

## What is the AI agent?

The AI agent is a contextual assistant available in any editor via `Ctrl + /`. It lets you interact with your document using natural language — generating text, applying formatting, analyzing data, and more. See [AI agent](../ai/ai-agent.md) for details.

## Can I create my own AI tools?

Yes. Custom AI tools are JavaScript functions registered in the AI plugin that expose AI-powered actions directly inside the editors. See [custom AI tools](../ai/custom-ai-tools.md) to get started.

For questions about plugin installation, styling, localization, and distribution, see the [Plugins FAQ](../../plugins/more-information/faq.md).
