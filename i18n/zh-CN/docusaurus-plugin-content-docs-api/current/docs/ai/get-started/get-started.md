# 入门指南

自定义 AI 工具是基于 ONLYOFFICE 插件系统构建的 AI 扩展程序。它们将编辑器与 AI 服务提供商相连接，并在文档内部直接提供智能操作——例如文本生成、翻译、数据分析以及其他自定义文档操作。

如果您希望直接开始编写代码，请前往[快速入门指南](quick-start/comment-text-ai-tool.md)，或在[交互式 Playground](playground.md) 中体验。
