# 常见问题

## ONLYOFFICE 支持哪些 AI 服务提供商？

AI 插件支持多种服务提供商，包括 OpenAI、DeepSeek、Google Gemini、Anthropic Claude、Mistral、Ollama，以及任何兼容 OpenAI API 格式的服务提供商。详情请参阅[自定义服务提供商](../ai/custom-providers.md)。

## 如何配置 AI 插件？

安装插件后，进入 **AI → 设置 → 编辑 AI 模型**，添加您的服务提供商并输入 API 密钥，然后选择每个模型的用途。完整的设置说明请参阅 [AI 插件指南](../ai/ai-plugin.md#configuring)。

## 什么是 AI 代理？

AI 代理是内置于编辑器中的上下文助手，通过 `Ctrl + /` 调用。它允许您使用自然语言与文档交互——包括生成文本、应用格式、分析数据等。详情请参阅 [AI 代理](../ai/ai-agent.md)。

## 我可以创建自定义 AI 工具吗？

可以。自定义 AI 工具是在 AI 插件中注册的 JavaScript 函数，可将 AI 功能直接集成到编辑器中。请参阅[自定义 AI 工具](../ai/custom-ai-tools.md)开始使用。

## 有关于插件的问题？

有关插件安装、样式、本地化和分发的问题，请参阅[插件常见问题](../../plugins/more-information/faq.md)。
