# 入门指南

宏是直接在 ONLYOFFICE 文档中运行的轻量级 JavaScript 脚本，无需安装。编写一次宏，随时运行，即可在文档、电子表格和演示文稿中自动执行重复性任务。

如果您希望直接开始编写代码，请前往[快速入门指南](quick-start/hello-world-macro.md)，或在[交互式 Playground](playground.md) 中体验。
