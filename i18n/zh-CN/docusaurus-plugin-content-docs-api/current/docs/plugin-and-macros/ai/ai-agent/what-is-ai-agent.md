# 什么是 AI 助手

AI 助手是集成到 ONLYOFFICE 编辑器中的内联上下文助手。它作为 AI 插件的测试版功能提供，从 2.4.2 版本开始可用。

## 核心概念

AI 助手通过 `Ctrl + /` 调用，以悬浮输入面板的形式直接出现在编辑器中。与 AI 插件的侧面板不同，助手以内联方式工作——在上下文中输入请求，结果立即应用于文档。

![AI 助手提示](/assets/images/plugins/ai-agent-prompt.png#gh-light-mode-only)![AI 助手提示](/assets/images/plugins/ai-agent-prompt.dark.png#gh-dark-mode-only)

助手：

- 理解用于常见编辑任务的自然语言请求。
- 通过调用已注册的**工具**来执行这些请求——这些工具是通过 Office API 与文档交互的函数。
- 保存对话历史，允许通过后续指令进行迭代优化。

## 在 AI 系统中的角色

AI 助手位于 AI 插件和自定义 AI 工具之间：

```
AI 插件（提供商连接）
    └── AI 助手（自然语言接口）
            └── 工具（作用于文档的注册函数）
```

助手不直接修改文档。它为用户的请求选择适当的工具，将参数传递给它，由工具执行实际的文档操作。

## 助手能做什么

- **文本生成与改写。** 创建新内容或增强现有文本——摘要、创意、改写、语气调整。
- **智能格式化。** 应用以自然语言描述的格式更改，无需浏览菜单。
- **数据分析与可视化。** 汇总、排序和筛选电子表格数据；根据文字描述生成图表和可视化表示。

有关内置工具的完整列表，请参阅[工具调用](tool-calling.md)。
